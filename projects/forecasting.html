The situation

Planning ran on a single top-down number that nobody fully believed. Pipeline wasn't weighted by stage reality, retention drivers weren't modeled, and every board cycle turned into a debate over whose gut was right. Variance between forecast and actuals was wide enough to erode trust in the number itself.

The model

Expected revenue was rebuilt bottom-up: stage-weighted pipeline plus the retained base, then flexed across three scenarios so leadership saw the range instead of a false point estimate.

How it was built

  1. Rebuild pipeline stages with historical stage-to-close conversion, not flat probabilities.
  2. Model the retained base separately using cohort renewal and churn signals.
  3. Blend into an expected-revenue equation, weighted by scenario factor.
  4. Derive required pipeline coverage from the blended win rate.
  5. Publish conservative / base / stretch each cycle with the assumptions exposed.

The outcome

  • Variance cut by ~30% as the forecast tracked actuals across cycles.
  • Board conversations shifted from "is the number right?" to "which scenario are we steering toward?"
  • Coverage targets became a derived output, so pipeline gaps surfaced early instead of at quarter-end.

A believable range beats a precise number that's wrong. The forecast finally became something the business could actually plan on.
